| ENH-15 | Crop a photo, both while uploading it and after it is already uploaded | **Half built - spec 032.** AT CAPTURE it is done the way the keeper chose: *"changing the photo from the beginning rather than a rendering trick"*. | ENH-16 | Improve the take-a-photo journey: *"When using the take photo functionality, I'd like it to automatically open chrome or google if installed, and then pop a notification etc to let the user easily be able to switch back to the app. Currently the user journey is quite bad."* | **The mechanism as asked is mostly not available to a web app, so capture the complaint rather than the remedy.** A page cannot detect whether Chrome is installed and cannot launch it (`intent://` is Android-only and is refused from an installed PWA context); a notification to switch back needs Notification permission *plus* the service worker, and on iOS only works once the app is installed to the home screen — and there is no reliable event that fires at the moment the OS camera hands control back. **Not yet reproduced, and it needs one observation before a spec can be written:** which context is this — the installed PWA, a normal browser tab, or an in-app webview opened from a link in another app?
